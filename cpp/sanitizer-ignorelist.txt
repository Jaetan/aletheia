# Sanitizer ignorelist for the C++ binding.
#
# Format: one entry per line, see
# https://clang.llvm.org/docs/SanitizerSpecialCaseList.html.  This file is
# passed as -fsanitize-ignorelist= to all sanitizer-instrumented builds
# (-DALETHEIA_SANITIZER=...).  Aletheia's own code remains fully
# instrumented; only specific third-party vendored sources fall under the
# ignorelist.
#
# Each entry below states what it suppresses and why.

# OpenXLSX vendors a fork of miniz called "zippy".  zippy.hpp performs
# unaligned loads and stores on byte buffers (mz_uint32 accesses at
# non-4-byte boundaries) and passes a null pointer to a library call, the
# well-known miniz patterns; safe on x86_64 where the CPU permits it but UB
# per the C++ standard.  XLStyles.cpp loads a bool from spreadsheet bytes
# that can hold values other than 0 and 1.  Measured by building the Excel
# tests under UBSan with this list withheld and recovery enabled (the
# measurement script lives with the review record): every report came from
# those two files.  Aletheia uses OpenXLSX read-only via the optional excel
# loader and cannot patch the vendored zippy without forking OpenXLSX, so
# all OpenXLSX vendored code is suppressed; aletheia-cpp's own source
# remains fully instrumented.
